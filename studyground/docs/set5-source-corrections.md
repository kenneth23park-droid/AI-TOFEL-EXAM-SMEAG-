# SET 5 작업 사본 교정 기록

2026-10-06. Downloads의 사용자 원본 세 장은 변경하지 않았다. 저장소의 작업 사본을
교정하고 `tools/build_set5.mjs`로 다시 빌드했다. 정답지의 답은 바꾸지 않았다.
교정 전 문제지·스크립트는 각각 `.bak-set5-original`로 보관한다.

| 위치 | 원본 문제 | 작업 사본 교정 |
| --- | --- | --- |
| W1 Q1 | `to find`가 한 타일이므로 정답은 7개 타일인데 빈칸 8개 | 빈칸 7개 |
| W1 Q4 | 정답은 10개 타일인데 빈칸 9개 | 빈칸 10개 |
| W1 Q10 | 정답에 필요한 `to` 타일 없음, 빈칸 5개 | `to` 타일 추가, 빈칸 6개 |
| L2 Q4–5 | 문제의 남학생·여교수와 스크립트 화자 성별 반대 | 이 대화의 `Woman:` / `Man:` 라벨만 교환 |

W1 Q3의 `Do you know when it is now?`, 문장 오타, L2 Q3의 어색한 보기 등은
정답 조립·채점에 영향을 주는 확정적 오류가 아니므로 원문을 유지했다.

별도로 파서 `questionRange()`가 공백 없는 원본 머리글 `Question1-3`을 받아들이도록
고쳤다. 이전에는 첫 문항 스크립트가 한 칸 밀리고 뒤의 대화·강의에도 짧은 응답이
붙었다. 문서의 머리글은 바꾸지 않았다. SET 5 회귀테스트는 세 응답의 정확한 문구와
나머지 네 대본의 시작, 작업 문서 재빌드와 팩 전체의 동일성을 검사한다.

원본 SHA-256:

- 문제지: `3c633d046d8b4e7b979898ef45b445f851dc991d45ceb6de165e407d47cec6d3`
- 스크립트: `17c2ea3cadd5ac9d24e998fe966432bc4648d497795a18394dc4983f7c3e6b4e`

`tools/correct_set5_sources.py`는 이 교정을 재현하며 재실행해도 중복 적용하지 않는다.
OOXML의 대상 문단 텍스트만 교체하고 `word/document.xml` 외 ZIP 항목의 바이트는
보존한다. 렌더러가 설치되어 있지 않아 Word 문서 페이지 렌더 검증은 수행하지 못했다.
시험 웹 화면 검증은 별도 수행한다.
