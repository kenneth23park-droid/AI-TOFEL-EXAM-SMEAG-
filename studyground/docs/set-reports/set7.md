### Audio (2026-11-13)

All 33 clips were made with ElevenLabs from `tts-voices-set7exam-11labs.json` on a machine without Python or ffmpeg, using a Node port of the synth step of `tools/tts_multivoice.py` (same model, voices, speeds and segment cache names in `media/tts/_segments/`). Two differences from the normal tool:

- The four conversations (`l1-q09-10`, `l1-q11-12`, `l2-q04-05`, `l2-q06-07`) are the five lines joined end to end **without the 0.4 s gap** ffmpeg normally inserts.
- `tools/verify_audio.py` (faster-whisper) has **not** run, so every clip is listed below as failing the speech check. In its place each clip was transcribed with ElevenLabs speech-to-text (`scribe_v1`) and compared with the script: 31 at 0–1% WER; `l1-q15-16` 3.9% ("Bootcamp" heard as "boot camp", "Room 415" spelling) and `s2-q3` 6.7% ("Alright" heard as "All right") — spelling only, the audio says the script.

To clear this section run `python3 tools/tts_multivoice.py --manifest tts-voices-set7exam-11labs.json` on a machine with Python + ffmpeg — it reuses the cached segments (no new API cost), re-stitches the conversations with gaps and runs the audio gate.
