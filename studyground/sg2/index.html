Frequently asked questions자주 묻는 질문

What does SMEAG StudyGround include?SMEAG StudyGround는 무엇을 제공하나요?

Realistic New TOEFL mock tests, a Practice Zone of format-specific questions, Click & Learn video lectures, plus a study planner, vocabulary bank and error log. 실전형 New TOEFL 모의고사, 유형별 연습존, Click & Learn 영상 강의, 그리고 학습 플래너·단어장·오답노트를 제공합니다.

How does AI scoring work?AI 채점은 어떻게 동작하나요?

Reading & Listening are auto-scored against the answer key; Speaking & Writing run through a LangGraph pipeline that returns rubric-aligned feedback, with a rule-based fallback when the LLM is unavailable. 리딩·리스닝은 정답키로 자동 채점하고, 스피킹·라이팅은 LangGraph 파이프라인으로 루브릭 기반 피드백을 제공합니다. LLM을 못 쓰면 규칙 기반으로 자동 폴백합니다.

Is the content real exam material?실제 시험 자료인가요?

Practice uses SMEAG's own SET 1 mock — 91 questions with real listening/speaking audio, verified against the source answer key. 연습은 SMEAG 자체 SET 1 모의고사(91문항, 실제 리스닝/스피킹 오디오)를 사용하며 원본 정답키로 검증했습니다.

Can I study offline?오프라인으로 학습할 수 있나요?

Yes — StudyGround runs in a local, no-network mode for on-site use, and a cloud mode with Supabase + AI scoring when online. 네 — 현장용 무네트워크 로컬 모드와, 온라인 시 Supabase+AI 채점 클라우드 모드를 모두 지원합니다.
